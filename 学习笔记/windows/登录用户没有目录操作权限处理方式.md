## 先确认目录权限

执行：

Get-Acl "D:\Fore\nodejs\node_global" | Format-List
结果：
```
PS C:\Users\aihelp> Get-Acl "D:\Fore\nodejs\node_global" | Format-List Path : Microsoft.PowerShell.Core\FileSystem::D:\Fore\nodejs\node_global Owner : BUILTIN\Administrators Group : LAPTOP-5AUD5J89\None Access : BUILTIN\Users Allow ReadAndExecute, Synchronize NT AUTHORITY\Authenticated Users Allow ReadAndExecute, Synchronize BUILTIN\Administrators Allow FullControl NT AUTHORITY\SYSTEM Allow FullControl Audit : Sddl : O:BAG:S-1-5-21-3389487829-1072830420-2182670640-513D:(A;OICIID;0x1200a9;;;BU)(A;OICIID;0x1200a9;;;AU)(A;OICIID ;FA;;;BA)(A;OICIID;FA;;;SY)
```
以及：

Get-Acl "D:\Fore\nodejs\node_global\node_modules" | Format-List
结果：
```
PS C:\Users\aihelp> Get-Acl "D:\Fore\nodejs\node_global\node_modules" | Format-List Path : Microsoft.PowerShell.Core\FileSystem::D:\Fore\nodejs\node_global\node_modules Owner : BUILTIN\Administrators Group : LAPTOP-5AUD5J89\None Access : BUILTIN\Users Allow ReadAndExecute, Synchronize NT AUTHORITY\Authenticated Users Allow ReadAndExecute, Synchronize BUILTIN\Administrators Allow FullControl NT AUTHORITY\SYSTEM Allow FullControl Audit : Sddl : O:BAG:S-1-5-21-3389487829-1072830420-2182670640-513D:(A;OICIID;0x1200a9;;;BU)(A;OICIID;0x1200a9;;;AU)(A;OICIID ;FA;;;BA)(A;OICIID;FA;;;SY)
```

对，这个结果已经**100%解释了为什么 `npm install -g` 会 EPERM**。

你当前：

```text
D:\Fore\nodejs\node_global
Owner: BUILTIN\Administrators
```

权限是：

```text
BUILTIN\Users                  ReadAndExecute
Authenticated Users            ReadAndExecute
Administrators                 FullControl
SYSTEM                         FullControl
```

而你当前登录用户 `aihelp` 属于 `Users`，因此它只有：

```text
ReadAndExecute
```

没有：

```text
Write
Modify
Create folders
```

所以 npm 执行：

```text
mkdir D:\Fore\nodejs\node_global\node_modules\@deepseek-ai
```

自然就得到：

```text
EPERM
```

## 推荐的修复方式

因为这是你专门用于 npm 全局包的目录，我建议直接给当前用户 `aihelp` **完全控制权限**。

### 1. 以管理员身份打开 PowerShell

执行：

```powershell
icacls "D:\Fore\nodejs\node_global" /grant "aihelp:(OI)(CI)F" /T
```

如果你的 Windows 用户实际显示为：

```text
LAPTOP-5AUD5J89\aihelp
```

也可以使用：

```powershell
icacls "D:\Fore\nodejs\node_global" /grant "LAPTOP-5AUD5J89\aihelp:(OI)(CI)F" /T
```

不过通常：

```powershell
"aihelp:(OI)(CI)F"
```

就够了。

---

## 2. 检查权限

执行：

```powershell
Get-Acl "D:\Fore\nodejs\node_global" | Format-List
```

应该出现类似：

```text
BUILTIN\Users Allow ReadAndExecute
NT AUTHORITY\Authenticated Users Allow ReadAndExecute
BUILTIN\Administrators Allow FullControl
NT AUTHORITY\SYSTEM Allow FullControl
LAPTOP-5AUD5J89\aihelp Allow FullControl
```

重点是出现：

```text
aihelp Allow FullControl
```

---

## 3. 不要用管理员 PowerShell 测试 npm

关闭当前管理员 PowerShell。

重新打开**普通 PowerShell**，然后：

```powershell
whoami
```

应该是：

```text
laptop-5aud5j89\aihelp
```

然后测试：

```powershell
New-Item -ItemType Directory -Path "D:\Fore\nodejs\node_global\node_modules\test-permission"
```

如果成功：

```powershell
Remove-Item "D:\Fore\nodejs\node_global\node_modules\test-permission"
```

这一步成功就说明权限已经彻底解决。

---

然后：


再：

正常情况下应该在：

```text
D:\Fore\nodejs\node_global
```

附近。


## 你的 Node 环境现在最终可以整理成这样

其实你现在这套结构已经挺合理了：

```text
Node.js
D:\Fore\nodejs
        │
        ├── node.exe
        ├── npm
        ├── npx
        │
        └── node_global
              │
              ├── node_modules
              │     └── @deepseek-ai
              │           └── dsh
              │
              └── ...
```

npm cache：

```text
D:\DevCache\npm
```

配置：

```text
prefix  = D:\Fore\nodejs\node_global
cache   = D:\DevCache\npm
registry = https://mirrors.huaweicloud.com/repository/npm/
```

这样以后：

```powershell
npm install -g xxx
```

都会写入 D 盘，而且**普通用户就可以完成安装，不需要每次以管理员身份运行 PowerShell**。

### 一个额外建议

你这个目录目前的 Owner 是：

```text
BUILTIN\Administrators
```

**不需要为了 npm 把 Owner 改成 `aihelp`。**

保持：

```text
Owner = Administrators
```

同时增加：

```text
aihelp = FullControl
```

是更合适的做法。

也就是说，我们只需要解决：

> **`aihelp` 没有写权限**

而不需要改变目录所有权。
