需求描述

iLocalize的AI功能，也要开始按照使用量计费，需要确认AI功能的计费逻辑。
在确定AI功能的计费逻辑时，需要拉取AI功能相关的使用量，即：多少字符数，对应多少输入和输出的Token。
具体需要拉取的数据表格如下：
时间范围：2025 9月1日 00:00:00——2025 9月30日 23:59:59
数据指标：

|   |   |   |   |   |   |   |
|---|---|---|---|---|---|---|
|公司|项目|总字数|总字符数|大模型|输入Token数量|输出Token数量|
||||||||

拉取所有公司的数据：只有后台备注了公司的项目才需要拉取，如果没有公司，则不需要拉取。
总字数和总字符数的拉取逻辑：
1、如果一个文件的源文件的字数是1000字，AI预翻译为2个语言，总字数计算为2000
2、如果一个文件被AI预翻译了两次，产生两次AI译文，则计算2次的总字数和总字符数
3、如果一个文件已经被删除了，也需要被计算。
